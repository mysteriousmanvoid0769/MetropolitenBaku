# Metro Simulation Project

Этот проект представляет собой симуляцию работы метрополитена с несколькими линиями, где используется многозадачность для моделирования движения поездов по станциям. Проект включает несколько классов для каждой линии метрополитена и поддерживает параллельное выполнение для каждой линии с использованием потоков.

## Описание

Проект моделирует работу метрополитена, разделенного на несколько линий, таких как красная, фиолетовая, зеленая и светло-зеленая линии. Каждая линия содержит свои станции, и симуляция позволяет поездам двигаться между ними, учитывая виртуальное время.

Многозадачность позволяет одновременно выполнять симуляцию для всех линий метрополитена, что имитирует реальную работу нескольких потоков поездов.

## Технологии

- CMake
- C++

## Структура проекта

Проект состоит из нескольких основных частей:

* **Station**: Структура, представляющая станцию с указателями на следующую и предыдущую станцию.
* **Virtual\_time**: Класс, отвечающий за виртуальное время в симуляции. Он управляет временем, которое обновляется и используется для моделирования движения поездов.
* **Red\_line**, **Violet\_line**, **Light\_green\_line**, **Green\_line**: Классы, моделирующие различные линии метрополитена.

Каждая линия работает в своем потоке, и они взаимодействуют с мьютексами для синхронизации данных.

### Классы и функции:

* **fill\_stations()**: Заполняет информацию о станциях для каждой линии.
* **move\_train()**: Моделирует движение поезда от станции к станции.
* **write\_to\_file()**: Записывает информацию о движении поездов в файл.

### 1. Подключение библиотеки:

Для использования этого проекта в своем приложении, включите основной заголовочный файл `metro.h`:

```cpp
#include "metro.h"
```


### 2. Запуск симуляции:

Создайте объекты для каждой из линий и запустите их в отдельных потоках. Пример кода для запуска симуляции:

```cpp
#include "metro.h"

int main() {
    // Инициализация мьютексов для синхронизации
    get_mtx();

    // Создание объектов для каждой линии метрополитена
    red_line::Red_line metro_red;
    violet_line::Violet_line metro_violet;
    light_green_line::Light_green_line metro_light_green;
    green_line::Green_line metro_green_line;
    
    // Запуск симуляции каждой линии в отдельных потоках
    std::thread red_thread(&red_line::Red_line::start, &metro_red);
    std::thread violet_thread(&violet_line::Violet_line::start, &metro_violet);
    std::thread light_green_thread(&light_green_line::Light_green_line::start, &metro_light_green);
    std::thread green_thread(&green_line::Green_line::start, &metro_green_line);

    // Ожидание завершения всех потоков
    red_thread.join();
    violet_thread.join();
    light_green_thread.join();
    green_thread.join();

    return 0;
}
```

### 3. Работа с виртуальным временем:

Для управления временем в симуляции используется объект `Virtual_time`, который можно обновлять:

```cpp
global_time.update_time(5);  // добавление 5 минут
```

### 4. Многозадачность:

Проект использует многозадачность для одновременной работы разных линий метрополитена. Каждая линия работает в своем потоке, что позволяет моделировать движение поездов в реальном времени для всех линий.
